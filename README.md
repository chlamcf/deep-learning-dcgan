# DCGAN Synthetic Augmentation for MNIST

## Overview

This project evaluates whether a convolutional generative adversarial network
(DCGAN) can generate useful synthetic MNIST digit images for CNN training-data
augmentation.

1. A CNN is trained on real MNIST images to establish a classification baseline.
2. A DCGAN is trained on MNIST training images.
3. The trained generator produces candidate synthetic digit images.
4. The frozen baseline CNN pseudo-labels the generated images.
5. Only high-confidence pseudo-labeled synthetic images are retained.
6. A second CNN is trained on the original MNIST training set plus the accepted
   synthetic images.
7. The baseline and augmented CNNs are evaluated on the same held-out MNIST
   test set.

The MNIST test split is excluded from GAN training, pseudo-labeling, synthetic
augmentation, and model fitting.

## Research Question

> Can high-confidence MNIST-like images generated by a DCGAN improve the
> held-out accuracy of a CNN digit classifier?

The experiment compares a CNN trained only on real MNIST images with a CNN
trained on real MNIST images plus 10,000 generated and pseudo-labeled images.

## Architecture

### CNN Classifier

The MNIST classifier is a convolutional neural network with:

- Two convolutional feature-extraction stages.
- ReLU activation functions.
- Max-pooling layers for spatial downsampling.
- A fully connected classification head.
- Ten output classes corresponding to digits 0 through 9.

The classifier is optimized with Adam and cross-entropy loss.

### DCGAN Generator

The generator maps a 100-dimensional latent vector to a grayscale 28×28 digit
image.

```text
100-dimensional latent vector
        │
        ▼
Transpose convolution + batch normalization + ReLU
        │
        ▼
Transpose convolution + batch normalization + ReLU
        │
        ▼
Transpose convolution + batch normalization + ReLU
        │
        ▼
Convolution + Tanh activation
        │
        ▼
Generated 1×28×28 grayscale digit image
```

The `Tanh` output constrains generated pixel values to the interval \([-1, 1]\),
matching the GAN data-normalization scheme.

### DCGAN Discriminator

The discriminator receives a grayscale digit image and predicts whether it is
a real MNIST image or a generated image.

```text
1×28×28 grayscale image
        │
        ▼
Strided convolution + LeakyReLU
        │
        ▼
Strided convolution + batch normalization + LeakyReLU
        │
        ▼
Strided convolution + batch normalization + LeakyReLU
        │
        ▼
Global average pooling
        │
        ▼
Single real/fake logit
```

The GAN uses binary cross-entropy with logits. Both generator and discriminator
are optimized with Adam using DCGAN-style momentum settings.

## Installation

Requires Python, PyTorch, Torchvision, Matplotlib, TorchMetrics and Torch-Fidelity.

```bash
pip install torch torchvision matplotlib "torchmetrics[image]" torch-fidelity
```

## Reproduction

### 1. Baseline CNN

The following command trains a CNN using only real MNIST training images:

```powershell
python -m src.train_cnn --epochs 10 --output-dir outputs/cnn_baseline
```

The baseline run creates:

```text
outputs/cnn_baseline/baseline_cnn.pth
outputs/cnn_baseline/baseline_metrics.json
```

### 2. DCGAN Training

The following command trains the DCGAN for 50 epochs and saves generated sample
grids at epochs 1, 10, 25, and 50:

```powershell
python -m src.train_gan --epochs 50 --sample-epochs 1,10,25,50 --output-dir outputs/gan --checkpoint-dir outputs/gan_models
```

The GAN run creates:

```text
outputs/gan/samples_epoch_001.png
outputs/gan/samples_epoch_010.png
outputs/gan/samples_epoch_025.png
outputs/gan/samples_epoch_050.png
outputs/gan/loss_history.csv
outputs/gan/metrics.json
outputs/gan_models/generator_epoch_50.pth
outputs/gan_models/discriminator_epoch_50.pth
```

The GAN loss curve is generated with:

```powershell
python -m src.plot_losses --csv-path outputs/gan/loss_history.csv --out outputs/gan/loss_curve.png
```

### 3. Synthetic-Augmentation CNN

The augmentation experiment adds 10,000 generated images to the original MNIST
training set.

A frozen baseline CNN assigns pseudo-labels to generated images. Only images
whose maximum predicted class probability is at least 0.95 are retained.

```powershell
python -m src.train_cnn --epochs 10 --output-dir outputs/cnn_augmented --synthetic-count 10000 --confidence 0.95 --gan-checkpoint outputs/gan_models/generator_epoch_50.pth --teacher-checkpoint outputs/cnn_baseline/baseline_cnn.pth
```

The augmented run creates:

```text
outputs/cnn_augmented/augmented_cnn.pth
outputs/cnn_augmented/augmented_metrics.json
```

If the generator does not produce enough high-confidence pseudo-labeled samples
within the configured candidate budget, the training script exits with an error.
Potential remedies include training the GAN longer, reducing `--confidence`, or
increasing `--max-candidates`.

## Results

### Classification Accuracy

Both classifiers were trained for 10 epochs and evaluated on the same held-out
MNIST test set.

| Model | Training Data | Final Test Accuracy | Best Test Accuracy |
|---|---|---:|---:|
| Baseline CNN | Real MNIST training images only | 99.29% | 99.31% |
| Augmented CNN | Real MNIST plus 10,000 generated pseudo-labeled images | 99.33% | 99.34% |

The synthetic-augmentation CNN reached a final held-out accuracy of **99.33%**,
compared with **99.29%** for the real-only baseline.

\[
99.33\% - 99.29\% = 0.04
\]

This corresponds to a final accuracy improvement of **0.04 percentage points**.

The best observed accuracy also improved slightly:

\[
99.34\% - 99.31\% = 0.03
\]

The augmented model achieved a best test accuracy that was **0.03 percentage
points** higher than the baseline model's best observed accuracy.

### GAN Quantitative Evaluation

The DCGAN was trained for 50 epochs and evaluated with Fréchet Inception
Distance (FID).

| Metric | Result |
|---|---:|
| GAN training epochs | 50 |
| FID | 3.464 |

The final FID was **3.464**. Lower FID values indicate that generated images and
real images are closer in the Inception feature space used by the metric.

FID is a distribution-level measure and does not establish that every generated
image is a correct digit, has a correct pseudo-label, or improves classification
by itself. The augmented CNN's held-out test accuracy provides the downstream
evaluation of synthetic-image utility.

## Qualitative GAN Evaluation

The repository includes generated sample grids from several points in GAN
training:

```text
outputs/gan/samples_epoch_001.png
outputs/gan/samples_epoch_010.png
outputs/gan/samples_epoch_025.png
outputs/gan/samples_epoch_050.png
```

These grids document the progression of the generator during training.

- **Epoch 1** samples are expected to show noisy, incomplete, or weakly
  structured digit-like patterns.
- **Epoch 10** samples are expected to show increasingly recognizable digit
  structure, though blur, broken strokes, and inconsistent proportions may
  remain.
- **Epoch 25** samples can be inspected for sharper shapes, improved digit
  legibility, and broader variation in writing style.
- **Epoch 50** samples provide the final qualitative view of digit clarity,
  diversity, and potential mode collapse.

The qualitative evaluation considers:

1. Digit legibility and continuity of handwritten strokes.
2. Diversity of digit shapes, sizes, and writing styles.
3. Evidence of mode collapse, such as a narrow set of repeated patterns.
4. Artifacts including disconnected strokes, blur, implausible digit shapes, or
   blank images.
5. Visual changes between early and late training epochs.

The sample grids, FID score, and GAN loss curve together provide a more complete
evaluation of generation quality than any one output in isolation.

## Interpretation

The experiment indicates that DCGAN-generated synthetic images produced a small
improvement in held-out CNN classification accuracy.

```text
Baseline CNN final test accuracy:  99.29%
Augmented CNN final test accuracy: 99.33%
Final accuracy difference:         +0.04 percentage points
```

This improvement is positive but modest. MNIST is a relatively simple benchmark
for convolutional classifiers, and the real-only baseline already reaches
approximately 99.3% test accuracy. At that performance level, there is limited
room for data augmentation to produce large gains.

The results suggest that at least some generated images were realistic enough
and consistently pseudo-labeled enough to add useful variation to the training
set. The observed effect should nevertheless be interpreted carefully because
GAN and classifier performance can vary with:

- Random seed.
- GAN training duration.
- Generator quality.
- Pseudo-label confidence threshold.
- Number of accepted synthetic images.
- CNN architecture.
- Optimizer and learning-rate settings.

## Future Work

Potential extensions include:

- Repeating the experiment with multiple random seeds and reporting mean
  accuracy with standard deviation.
- Comparing synthetic-data counts such as 1,000, 5,000, 10,000, and 20,000.
- Sweeping pseudo-label confidence thresholds.
- Comparing DCGAN augmentation with a conditional GAN, which can generate
  images with known class labels.
- Reporting per-class accuracy to determine whether generated images help some
  digits more than others.
- Using a dedicated validation split for model selection rather than inspecting
  test accuracy across training epochs.
- Evaluating whether stronger GAN architectures improve downstream
  classification utility.
